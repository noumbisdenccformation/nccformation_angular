## 🚀 Déploiement (3 Étapes)

### 1. Connexion Vercel
- Aller sur https://vercel.com
- Se connecter avec GitHub

### 2. Import du Projet
- Add New → Project
- Sélectionner `nccformation_angular`
- Vercel détecte Angular automatiquement

### 3. Déployer
- Cliquer sur "Deploy"
- Attendre 2-3 minutes
- Site en ligne ! 🎉

**Temps total : 5 minutes**
